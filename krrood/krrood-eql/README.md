# krrood-eql

The entity query language.

krrood-eql is one of the distributions of [krrood](https://pypi.org/project/krrood/), Knowledge Representation & Reasoning Through Object Oriented Design. All krrood distributions share the `krrood` namespace package, so their import paths do not depend on which distributions are installed. `pip install krrood` installs all of them.

## Installation

```bash
pip install krrood-eql
```

Optional features:

- `pip install "krrood-eql[probabilistic]"`
- `pip install "krrood-eql[symbolic-math]"`

## Modules

- `krrood.entity_query_language`
- `krrood.inheritance_path_length`
