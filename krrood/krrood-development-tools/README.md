# krrood-development-tools

The krrood command: formatting, rule checks and generated agent instructions, and the CI test jobs a change needs.

krrood-development-tools is one of the distributions of [krrood](https://pypi.org/project/krrood/), Knowledge Representation & Reasoning Through Object Oriented Design. All krrood distributions share the `krrood` namespace package, so their import paths do not depend on which distributions are installed. `pip install krrood` installs all of them.

## Installation

```bash
pip install krrood-development-tools
```

## Modules

- `krrood.development_tools`
