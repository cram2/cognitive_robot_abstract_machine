# krrood-rustworkx-utils

Trees and graph visualization on rustworkx graphs.

krrood-rustworkx-utils is one of the distributions of [krrood](https://pypi.org/project/krrood/), Knowledge Representation & Reasoning Through Object Oriented Design. All krrood distributions share the `krrood` namespace package, so their import paths do not depend on which distributions are installed. `pip install krrood` installs all of them.

## Installation

```bash
pip install krrood-rustworkx-utils
```

Optional features:

- `pip install "krrood-rustworkx-utils[visualization]"`

## Modules

- `krrood.rustworkx_utils`
