# krrood-rdr

Ripple down rules.

krrood-rdr is one of the distributions of [krrood](https://pypi.org/project/krrood/), Knowledge Representation & Reasoning Through Object Oriented Design. All krrood distributions share the `krrood` namespace package, so their import paths do not depend on which distributions are installed. `pip install krrood` installs all of them.

## Installation

```bash
pip install krrood-rdr
```

## Modules

- `krrood.ripple_down_rules`
