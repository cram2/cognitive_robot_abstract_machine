# krrood-core

The light core of krrood: patterns, class diagrams, the symbol graph and exceptions.

krrood-core is one of the distributions of [krrood](https://pypi.org/project/krrood/), Knowledge Representation & Reasoning Through Object Oriented Design. All krrood distributions share the `krrood` namespace package, so their import paths do not depend on which distributions are installed. `pip install krrood` installs all of them.

## Installation

```bash
pip install krrood-core
```

Optional features:

- `pip install "krrood-core[ontomatic]"`

## Modules

- `krrood.bounds`
- `krrood.class_diagrams`
- `krrood.exceptions`
- `krrood.patterns`
- `krrood.singleton`
- `krrood.source_analysis`
- `krrood.symbol_graph`
- `krrood.utils`
